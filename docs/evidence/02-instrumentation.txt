## Privacy: client IPs are removed in the Collector before export
Before the attributes/scrub processor: client.address (a Docker-network IP) was present on every server span.
After: spans with client.address in this run: 0
Deleted rather than hashed: an unsalted hash of an IPv4 address can be reversed by hashing all 2^32 addresses.
